## Installation

Make sure Rust and Node.js are installed on your system. Then follow these steps:
1. Clone the repository using `git clone https://github.com/ChaosSchulInformatiker/minecraft-launcher`. 
2. Navigate into your local repository folder.
3. Execute the command `npm i`
4. Now you can start the launcher using `npm run tauri dev` or build it by using `npm run tauri build`
